# Priority mého života
Responzivní PWA-style webová aplikace inspirovaná principem čtyř kvadrantů důležitosti a naléhavosti.

## Funkce
- dashboard a životní semafor
- 4 životní oblasti
- cíle a progress
- Q1–Q4 matice
- automatické zařazení aktivit
- „Co je teď nejdůležitější?“ + focus timer
- statistiky Q1–Q4, proaktivita/reaktivita
- večerní vyhodnocení
- rotace motivačních myšlenek
- localStorage persistence
- responzivní mobil/desktop

## Nasazení
Statický web: nahrajte `index.html`, `style.css` a `app.js` do document root subdomény.
